Automated MACT Compensation Calculator

This is a configurable calculation worksheet, not a determination of the amount legally payable. Enter the multiplier and percentage assumptions applicable to the case/order. Review all heads and the governing law before relying on the result.

High Court / Appellate Draft Studio

Templates are structured drafting aids. High Court rules, court-fee requirements, annexures, limitation, jurisdiction and local formatting must be checked against the applicable court rules and case record before filing.

Field Mapping & Data Normalization

Maps alternate field names used by imported records to canonical MACT fields without deleting the original source value. Useful for CSV imports, older versions and custom fields.

Automated Application Test Runner

Runs local structural checks against the current HTML application: required DOM IDs, core functions, storage, record schema, duplicate IDs and common broken references. It does not replace legal review or browser/device testing.

Deletion Protection

When a local PIN is configured, this layer requires the same PIN before a record is moved to the Recycle Bin, before bulk deletion, and before local permanent empty-bin operations. This is an additional guard; it does not replace the existing app lock.
